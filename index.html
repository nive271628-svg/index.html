Smart Blind Stick

A hardware-software solution designed to restore independence for visually impaired individuals. The stick uses ultrasonic sensors to detect obstacles at short, medium, and long ranges — triggering a calibrated buzzer and vibration motor to warn the user before a collision occurs.

This project was built with a focus on real-world usability, compact form factor, and low power consumption — making it practical for everyday use. It demonstrates how simple embedded components can create a meaningful social impact.

Tech Stack: Arduino Uno, C/C++, Ultrasonic Sensor (HC-SR04), Buzzer, Vibration Motor
